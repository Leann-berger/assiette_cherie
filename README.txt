L’ASSIETTE CHÉRIE — MINI-SITE TP SEO
===================================

Ouverture : double-cliquer sur index.html (aucune installation nécessaire).

Pages :
- index.html : page d’accueil, concept et spécialités
- jambalaya.html : article sur le jambalaya
- gumbo.html : article sur le gumbo
- cuisine-cajun.html : article sur les spécialités cajun
- assets/style.css : feuille de style responsive
- assets/*.svg : illustrations originales (non photographiques), accessibles avec alt

SEO appliqué : title et meta description uniques, lang=fr, un H1 par page,
HTML sémantique, liens internes, URL descriptives, images avec alt, responsive.

Avant une vraie mise en ligne :
- Remplacer les illustrations par des photos autorisées des vrais plats, si disponibles.
- Ajouter adresse exacte, téléphone, horaires, carte réelle et réservation.
- Obtenir un domaine puis ajouter les balises canonicals et un sitemap XML au domaine réel.
- Vérifier l’indexation via Google Search Console et la fiche d’établissement.
- Le restaurant est fictif : ne pas diffuser les données comme celles d’un commerce réel.
- Les liens vers Google Fonts nécessitent Internet ; en leur absence, polices système de repli.
